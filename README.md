# עומסי תנועה – שלב 1 (PWA)

## מה יש בשלב הזה
- **רשימת מיקומים** – שם, קואורדינטות, זום, וספי עומס לכל מיקום. אפשר להדביק קישור מוייז/גוגל מפות או לקחת מיקום נוכחי.
- **מפת וייז חיה** (ה-iframe הרשמי של וייז) לכל מיקום + כפתור לפתיחה באפליקציית וייז.
- **ניתוח צילום מסך** – מזהה צבעי עומס (צהוב/כתום/אדום/אדום כהה) ומחזיר מדד 0–100 ופסק דין: זורם / בינוני / כבד.
- **סימון אזור** – גוררים מלבן על התמונה כדי לנתח רק כביש/צומת מסוים, ושומרים אותו למיקום.
- **שיתוף מהגלריה** – אחרי התקנה, "שתף" על צילום מסך → "עומסים" פותח וינתח אותו.
- היסטוריית 30 בדיקות אחרונות לכל מיקום. הכל נשמר מקומית בטלפון.

## התקנה בטלפון (פעם אחת, ~5 דקות)
PWA חייבת לרוץ מכתובת https. הדרך החינמית הפשוטה – GitHub Pages:
1. צור חשבון ב-github.com ← New repository ← שם: `traffic` ← Public ← Create.
2. "uploading an existing file" ← גרור את **כל הקבצים שבתיקייה** (כולל תיקיית icons) ← Commit.
3. Settings ← Pages ← Source: `Deploy from a branch`, Branch: `main` / `root` ← Save.
4. אחרי דקה-שתיים הכתובת תהיה `https://<שם-משתמש>.github.io/traffic/`.
5. פתח אותה ב-Chrome באנדרואיד ← תפריט ⋮ ← **"הוסף למסך הבית" / "התקן אפליקציה"**.

## מגבלה ידועה (תטופל בשלב הבא)
דפדפן לא מורשה לצלם תוכן של iframe מאתר אחר, ולכן בשלב 1 הצילום ידני (צילום מסך → שיתוף לאפליקציה).
בשלב 2: עטיפה כ-APK אנדרואיד עם WebView שיצלם את המפה אוטומטית ויריץ בדיקות לפי לוח זמנים + התראות.

## כיול צבעים
טווחי הצבעים ב-`analyzer.js` (`DEFAULT_CALIBRATION`) הם ניחוש ראשוני. שלח לי 3–5 צילומי מסך אמיתיים (עם עומס ובלי) ואכייל אותם.
